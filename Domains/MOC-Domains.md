## 📊 Domain Template

Each domain should have:
1. **MOC** — Map of Content with sub-topics
2. **Sub-folders** — Specific topics (e.g., `AI-ML/LLMs/`, `Software/Rust/`)
3. **Chapter/Topic notes** — Using `Templates/Chapter-Overview.md`
4. **Cross-links** — To Wiki patterns, Clippings, Projects
